# DTC Middleware v2.0.1

**Release Date:** 2026-11-01T21:04:29Z

## Release Notes

Fixes on top of v2.0.0 for the CK go-live.

- #971 fix(ck): store every CK effective rate as a fraction (CRMFAS-1449). DEFAM, HCF, Qander and Findio wrote "Rente effectief jaarlijks %" in percentage points, so HubSpot showed for example 839% with a monthly amount about 11 times too high, and the funnel showed the rate 100 times too high. The rate is now stored as the fraction HubSpot expects; sorting, the response comparison and credit protection read both units. Replaces #968. Proposals written before this release keep their old value until they are repaired.
- #972 fix(config): use the Lender & Spender production API token in prod.
- #973 chore(hcf): configure production credentials and accept tokenless callbacks.
