# DTC Middleware v1.11.3

**Release Date:** 2026-08-12T09:53:37Z

## Release Notes

## Hotfix: Findio / CA Auto Finance webhook callbacks

This hotfix restores automatic Findio (FL) callbacks when no webhook signing key is configured in production.

### Changes

- Allow CA Auto Finance webhook callbacks when  is not configured.
- Keep HMAC signature validation enabled whenever the signing key is configured.
- Add regression coverage for both signed and unsigned webhook configurations.

### Context

The previous release made webhook signature validation mandatory, while Findio's current integration and production configuration do not provide a signing key. This caused valid callbacks to be rejected before processing.

Included change: #670

### Follow-up

Obtain and configure an official Findio webhook signing key if supported, then verify the signed callback flow end to end before removing the compatibility fallback.
