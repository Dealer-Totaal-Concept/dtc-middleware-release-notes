# DTC Middleware v1.16.2

**Release Date:** 2026-10-22T07:50:16Z

## Release Notes

Fix FL proposal ranking when HubSpot scores arrive at different times.

- Wait for pending scores before assigning ranks. Return HTTP 503 without changing ranks if scores remain unavailable, allowing the HubSpot webhook to retry.
- Preserve the zero-score fallback for confirmed unpriced proposals and business-rule failures. Clear that fallback when pricing first becomes available.

Main backport: https://github.com/Dealer-Totaal-Concept/dtc-middleware/pull/902
Original hotfix: https://github.com/Dealer-Totaal-Concept/dtc-middleware/pull/898

The main backport passed 124 focused tests, TypeScript, lint, and formatting checks. GitHub CI and the release workflow provide the full build and deployment checks.

The existing independent stoplicht workflow and delayed-score end-to-end acceptance remain follow-up work for the workflow owners. This release does not change HubSpot workflow configuration.
